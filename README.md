# Portfolio demos — Andrii Drymchenko

Working demo projects (fictional brands). Live: https://zishwhwhw.github.io/portfolio-demos/

| Project | What it shows | Stack |
|---|---|---|
| `pizzeria/` | Neapolitan pizzeria site: menu with photos, cart, delivery zones, checkout, live order tracker, order → Telegram, EN/PL | HTML, CSS, JS |
| `coffee/` | Coffee subscription landing: subscription builder with live price, animated roast-curve chart, cut-off countdown | HTML, CSS, JS, SVG |
| `flowers/` | Flower shop Telegram Mini App: theme-aware, MainButton/BackButton/haptics, sizes, card message, delivery slots | Telegram WebApp SDK, JS |
| `barber-bot/` | Barbershop booking bot with staff chat, reminders, reviews + browser simulator | Python, aiogram 3, SQLite, pytest |
| `booking/` + `booking-bot/` | Telegram Mini App for salon booking; bot validates slots, stores visits, alerts admin, sends reminders | WebApp SDK, aiogram 3, SQLite, pytest |
| `miniapp/` + `bot/` | Shop Mini App with cart and Telegram Stars payments | WebApp SDK, aiogram 3, SQLite |
| `saas/` | SaaS landing with an interactive rota demo and pricing slider | HTML, CSS, JS |
| `restaurant/` | Restaurant site: menu, cart, pickup/delivery checkout, order → Telegram, EN/PL | HTML, CSS, JS |
| `scraper/` | 1,000-product scraper → CSV/Excel/JSON + interactive dashboard | Python, requests, BeautifulSoup, openpyxl |
| `barber/`, `dentist/`, `autoserwis/` | Small-business sites in Polish with booking/request forms | HTML, CSS, JS |
| `landing/` | 8 KB landing page, no framework | HTML, CSS |
